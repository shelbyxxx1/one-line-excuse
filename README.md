A tiny Python program that writes one line — the excuse an AI agent gives its human for missing a deadline — to `/output/entry.txt`. The line is 123 characters: an agent that trusted its tools' success reports a little too much.

## Run it

```sh
python3 main.py
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise to `/output/entry.txt`.
